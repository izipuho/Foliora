# План: приветствие пользователя в LiveSplashScreen

## [x] 1. Хранилище профиля

- Создать `FolioraProfileStore`.
- Хранить `displayName` в `NSUbiquitousKeyValueStore`.
- Использовать Foliora-общий namespace ключей.
- Пустую строку нормализовать в `nil`.
- Чтение имени не должно блокировать запуск приложения.

## [ ] 2. Первый запуск / onboarding

- Расширить существующий первый запуск с проверкой language pack.
- Добавить шаг представления пользователя.
- Имя необязательное.
- Шаг можно пропустить.
- Сохранять введённое имя через `FolioraProfileStore`.

## [ ] 3. Редактирование профиля

- Добавить редактирование имени в `SettingsView`.
- Разрешить изменить имя.
- Разрешить удалить имя и вернуться к состоянию без имени.

## [ ] 4. Greeting-модель

- Сделать отдельную логику выбора приветствия.
- Подготовить локализованный набор фраз с именем.
- Подготовить локализованный нейтральный набор без имени.
- При каждом показе LiveSplash случайно выбирать одну фразу.

## [ ] 5. LiveSplash UI и анимация

- Добавить приветствие в storyboard LiveSplash.
- Зафиксировать для него общий tag.
- Начальное состояние приветствия: скрыто.
- Во время существующего подъёма и уменьшения медальона одновременно проявлять приветствие.
- После завершения подъёма оставить существующий запуск качания символа без изменения его логики.

## [ ] 6. Интеграция

- Перед показом LiveSplash использовать локально доступное значение `displayName`.
- LiveSplash не ждёт iCloud-синхронизацию.
- Если имени локально нет — показывать случайное нейтральное приветствие.
- Если имя позже приехало через iCloud, использовать его при следующем показе LiveSplash.
