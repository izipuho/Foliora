# Privacy Policy for Foliora Bells

_Last updated: August 10, 2026_

Foliora Bells is a personal collection catalog application for storing information about bell collections, including collection names, item details, notes, storage locations, photos, documents, and 3D models that the user chooses to add.

## Data Collection

Foliora Bells does not collect, sell, or share personal information with third parties for advertising, analytics, or tracking purposes. The application does not use advertising networks and does not track users across apps or websites.

The user may optionally provide a display name for personalized greetings. The display name is stored using Apple's iCloud key-value storage so it can be available on the user's devices signed in to the same Apple ID. It can be changed or deleted in the application settings.

## Data Storage

Collection data is stored on the user's device. Media files and catalog details remain under the user's control unless the user enables Apple services such as iCloud synchronization, iCloud backup, or CloudKit sharing.

When iCloud synchronization or sharing is enabled, Apple may process catalog data, media, and sharing participant information according to the user's Apple ID, iCloud, and CloudKit settings. Foliora Bells uses these Apple services only to synchronize, back up, and share the user's catalog data as requested by the user.

When a user shares a collection or accepts a shared collection, Apple CloudKit manages the invitation and may provide participant information, such as a participant's display name, role, and acceptance status. Foliora Bells displays this information only to support the sharing feature.

## Photos, Camera, and Photo Library

Foliora Bells may request access to the camera or photo library so the user can attach photos to catalog items. Photos are used only for catalog features selected by the user, including local photo analysis that suggests item details from images.

Photo analysis uses Apple system frameworks on the device to inspect the selected image, recognize visible text and objects, and generate suggested catalog values such as tags, title, notes, material, condition, acquisition year, or origin hints. These suggestions are shown for user review and are not saved unless the user accepts them.

When the app translates photo-analysis suggestions into the user's language, it uses Apple's Translation framework. The app may prompt the user to download the required Apple language model. Foliora Bells does not send photos, catalog contents, or generated suggestions to a Foliora server for analysis or translation, and these features are not used for advertising or cross-app tracking.

## Place Search and Maps

Foliora Bells uses Apple MapKit to search for and display places associated with catalog items. Search text and related map requests may be processed by Apple according to Apple's privacy policy. The application does not request or collect the device's current location for this feature.

## Import and Export

Foliora Bells may allow users to import or export catalog archives. Exported files are created only when requested by the user and can contain catalog data and media selected for export. Users are responsible for how they store or share exported files outside the application.

## Account Registration

No separate Foliora Bells account registration is required to use the application. Apple ID or iCloud account features are managed by Apple when the user chooses to enable Apple synchronization, backup, or sharing services.

## Data Deletion

Users can delete catalog content in the application. If iCloud synchronization is enabled, deletions may synchronize through iCloud for the same Apple ID according to Apple's service behavior and the user's iCloud settings.

The optional display name can be deleted separately in the application settings. Data previously included in an exported archive or shared outside the application must be deleted from those locations by the user.

## Children's Privacy

Foliora Bells does not knowingly collect personal information from children. The application is a general-purpose catalog tool and does not include advertising, behavioral tracking, or a Foliora-operated account service.

## Changes to This Policy

This Privacy Policy may be updated when application features or data-handling practices change. The date at the top of this page identifies the latest revision.
